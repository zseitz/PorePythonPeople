# Future Plans

This repository will continue evolving through work in the Gundlach lab after conclusion of the course. 

- Zacharias Seitz is the primary author and lead maintainer for ongoing software improvements.
- Future development will focus on making the runtime architecture more robust, extending the GUI tools, and keeping the policy/guardrail model aligned with lab workflows.
- The lab will prioritize local-first operation, reproducibility, and clear audit trails for each workflow.
- Documentation, tests, and policy files will remain first-class artifacts as the project grows.

The following members will also be recognized as authors of this work:
Yukun Li, Daniel Mendoza, Riya Patel, Tobias Rangel-Guillen, and Hannah Boyer. 

This software is intended to be released in an open-source manner.
